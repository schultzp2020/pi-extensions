Design package

Pi Model Advisor

An orchestrator-neutral Pi extension that recommends an eligible physical chat model and thinking level from bounded native classifier answers. It never switches the parent model and never launches an agent.

Implementation state: authorized. Complete seven tickets locally on one integration branch; no push, PR, publication, or live model tests.

Agent handoff

Compact continuation context, source references, settled decisions, and the exact next action.

System boundary

Any Pi-connected orchestrator proposes a subtask
↓
Pi supplies scoped or authenticated available models
↓
One native classifier answers three choice questions and one bool question
↓
Deterministic policy applies user configuration and constraints
↓
Structured recommendation or typed failure; no fallback
↓
Optional caller-owned preflight → exact selection approval → caller's existing launcher

Pi owns classifier discovery, credentials, transport retries, supported thinking levels, structured tool execution, and usage accounting. Advisor owns strict validation and deterministic policy. Config-only task profiles define routine levels; stronger compatible proposals return approval_required and require fresh exact user approval. Native classification asks three choice questions and one bool question. Configuration is global-only and changes apply through /reload.
